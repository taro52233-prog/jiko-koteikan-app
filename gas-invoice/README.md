# 請求書 自動作成・メール送信システム（Google Apps Script）

Google スプレッドシート＋Google Apps Script（GAS）＋Gmail だけで動く、
**請求書PDFの自動作成〜メール送信**の仕組みです。サーバー不要・無料で運用できます。

- ✅ スプレッドシートの請求データからPDFを自動生成し、Gmailで送信
- ✅ 消費税（10%/8%の税率別集計）・インボイス制度の登録番号に対応
- ✅ **画面フォーム**から1件ずつ作成・送信（ウェブアプリ）
- ✅ **一括送信**（「未送信」の行をまとめて送信）
- ✅ **時間トリガー**で毎日自動送信も可能
- ✅ 送信前プレビュー（Gmailの下書きに保存）、控えのBCC、DriveへのPDF保存

---

## 1. セットアップ手順

### ステップ1：スプレッドシートを用意し、スクリプトを貼り付ける

1. [Google スプレッドシート](https://sheets.new) を新規作成します。
2. メニュー **拡張機能 → Apps Script** を開きます。
3. このフォルダ（`gas-invoice/`）内の **`.gs` ファイルと `.html` ファイル**を、
   Apps Script エディタに同じ名前で作成して貼り付けます。
   - `.gs` ファイル：`Config` `Setup` `Util` `Invoice` `Mailer` `Main` `WebApp`
     （エディタ左「＋」→「スクリプト」で追加。既定の `Code.gs` は削除してOK）
   - `.html` ファイル：`InvoiceTemplate` `Form`
     （「＋」→「HTML」で追加。**拡張子 `.html` は付けず**「InvoiceTemplate」「Form」という名前で作成）
   - **マニフェスト**：エディタ左下「⚙ プロジェクトの設定」で
     「`appsscript.json` マニフェスト ファイルをエディタで表示する」にチェックを入れ、
     `appsscript.json` の中身をこのフォルダの内容に置き換えます。

> 💡 `clasp`（GAS用CLI）を使えるなら、このフォルダをそのまま `clasp push` で反映できます。

### ステップ2：初期セットアップを実行

1. スプレッドシートを**再読み込み**すると、上部メニューに **「📄 請求書」** が現れます。
2. **📄 請求書 → ① 初期セットアップ** を実行します。
   - 初回は権限の許可を求められます（Gmail送信・スプレッドシート・Drive）。
     「詳細」→「（プロジェクト名）に移動」→「許可」で進めてください。
3. 「設定」「請求データ」「明細」の3シートが自動作成されます。

### ステップ3：自社情報を入力

**「設定」シート**に自社情報・振込先・登録番号などを入力します。

| 項目 | 例 |
|------|-----|
| 自社会社名 | 株式会社サンプル |
| 自社住所 | 〒000-0000 東京都〇〇区… |
| 登録番号 | T0000000000000（インボイス登録番号） |
| 振込先銀行／支店／口座種別／口座番号／口座名義 | … |
| 既定税率 | 10 |
| 請求番号プレフィックス | INV- |
| PDF保存フォルダID | （任意）DriveのフォルダID |
| 控えBCC | （任意）自分のアドレス等 |
| メール件名／本文テンプレート | `{{請求番号}}` などの差し込みタグが使えます |

## 2. 使い方

### A. スプレッドシートで作成・一括送信

1. **「請求データ」** に1行 ＝ 1請求を入力（宛先・件名・発行日・支払期限など）。
   - 請求番号は**空欄でOK**（送信時に自動採番）。自分で付けても構いません。
2. **「明細」** に品目・数量・単価・税率を入力し、**請求番号で紐付け**ます。
   - 請求番号を自分で決めた場合は、請求データと明細に**同じ番号**を入れてください。
   - 自動採番を使う場合は、明細側の請求番号も**空欄**にしておくと、
     「選択中の行を送信」または「未送信が1件だけの一括送信」時に自動で紐付きます。
3. 送信：
   - **📄 請求書 → ▶ 選択中の行を送信**（その1行だけ送信）
   - **📄 請求書 → ▶ 未送信をすべて送信**（ステータスが「未送信」の行をまとめて送信）
4. 送信されると、その行のステータスが **「送信済」** になり、送信日時が記録されます。

> 🔍 **送信前に確認したい**場合は **👁 選択中の行をプレビュー（下書き保存）**。
> 実送信せず、PDF添付済みのメールがGmailの「下書き」に保存されます。

### B. 画面フォームで1件ずつ作成・送信（ウェブアプリ）

1. Apps Script エディタ右上 **「デプロイ」→「新しいデプロイ」** を選択。
2. 種類 **「ウェブアプリ」**、実行するユーザー **「自分」**、
   アクセスできるユーザー **「自分のみ」**（社内共有なら適宜変更）で **デプロイ**。
3. 発行された **ウェブアプリURL** を開くと、スマホでも使える入力フォームが表示されます。
4. 宛先・明細を入力し、
   - **💾 保存のみ** … スプレッドシートに「未送信」で保存
   - **✉️ 作成して送信** … 保存＋その場でPDF生成・メール送信
   - いずれもスプレッドシートに記録され、あとから履歴を確認できます。

### C. 毎日自動で送信する（時間トリガー）

- **📄 請求書 → ⏰ 毎日の自動送信をON** で、毎日9時ごろに「未送信」を自動送信します。
- 止めるときは **⏰ 自動送信をOFF**。
- 「定期請求」に使う場合：請求データに次回分の行を追加し、ステータスを「未送信」にしておくと、
  翌朝に自動送信されます（自動採番も行われます）。

## 3. 仕組み（ファイル構成）

| ファイル | 役割 |
|----------|------|
| `appsscript.json` | マニフェスト（タイムゾーン・権限スコープ・ウェブアプリ設定） |
| `Config.gs` | シート名・列レイアウト・設定の読み込み |
| `Setup.gs` | メニュー登録・初期シート作成 |
| `Util.gs` | 金額/日付フォーマットなどの共通処理 |
| `Invoice.gs` | 明細集計・金額計算・HTML→PDF生成 |
| `InvoiceTemplate.html` | 請求書PDFの見た目（自由に編集可） |
| `Mailer.gs` | 件名/本文の組み立て・Gmail送信・下書き保存 |
| `Main.gs` | 送信の入口・自動採番・トリガー本体 |
| `WebApp.gs` | ウェブアプリの受け口（フォーム→シート追記→送信） |
| `Form.html` | 入力フォーム（モバイル対応） |

---

## 4. カスタマイズのヒント

- **請求書の見た目** … `InvoiceTemplate.html` のCSS/HTMLを編集。ロゴを入れる場合は
  `<img src="data:image/png;base64,...">` のようにBase64で埋め込むとPDFに反映されます。
- **メール文面** … 「設定」シートの「メール件名テンプレート」「メール本文テンプレート」。
  `{{宛先会社}} {{宛先担当者}} {{請求番号}} {{件名}} {{支払期限}} {{合計}}` などが差し込めます。
- **消費税の丸め** … 税率別に**切り捨て**で計算しています（`Invoice.gs` の `Math.floor`）。
  四捨五入等に変えたい場合はそこを修正してください。
- **列の並び** … `Config.gs` の `COL` / `ICOL` を変えれば、シートの列順を変更できます。

## 5. 注意事項

- Gmailの1日あたり送信数には上限があります（無料アカウントで概ね100通/日程度）。大量送信時は分割してください。
- ウェブアプリ／トリガーは**デプロイした本人のGmail・権限**で動作します。
- 送信は取り消せません。初回は「👁 プレビュー（下書き保存）」で内容を確認してから運用を始めることをおすすめします。
