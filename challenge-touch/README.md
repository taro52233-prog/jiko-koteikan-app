# チャレンジタッチ がんばり管理

進研ゼミから届く「【昨日のがんばり】」メール（Gmail）を自動で取り込み、息子2人の

- 今日ゲームしてよいか
- 今週・今月の取り組み状況
- 今月のゲーム時間（先月の全レッスンを終えていなければ減る）

を管理画面に出す仕組みです。Google Apps Script（無料）だけで動きます。

## ルール

**今日のゲーム**: 次のどれかを満たせばOK

1. 今日チャレンジタッチをやった
2. 今週（月曜〜日曜）の目標日数（初期値 5日）を達成している → 残りの日は休んでもOK
3. 今月号をすでに全て完了している → 月末まで休んでもOK

**翌月のゲーム時間**: 月末までに「◯月号を全て完了しました」メールが来なければ、翌月は1日30分減。

| | ふだん | 前の月が未完了 |
|---|---|---|
| 兄 | 60分 | 30分 |
| 弟 | 30分 | **0分** |

- 減るのは翌月の1か月だけで、その月を完了すれば次の月は元に戻ります（減り続けることはない）
- `ruleStartMonth`（初期値 2026年10月）より前の月の結果は問いません。ルールを伝える前の月で減らさないためです
- 弟が0分になるのが厳しすぎる場合は `minMinutes` で下限を決められます（例: 15）

**昇格（弟）**: **2か月つづけて**月内に全部終えたら、ふだんのゲーム時間が **60分**（兄と同じ）に上がります。

- 上がったあとは兄と同じ扱い（未完了の翌月だけ30分）で、30分に戻ることはありません
- 途中で1か月でも未完了があれば、連続の数え直し
- 設定は `children` の `promoteTo`（上がったあとの分数）と `promoteAfterMonths`（必要な連続月数）

## メールから自動で読み取るもの

実際のメールの形（2026年9月）に合わせています。

| メールの内容 | 使い方 |
|---|---|
| 件名・本文の「◯◯さん」 | どちらの子か（`keywords` に名前を入れる） |
| 本文先頭の「2026年9月24日(木)」 | やった日（メールは翌日届くので受信日ではなくこちらを使う） |
| 「レッスン数 国語:5回 算数:4回」 | その日のレッスン数（合計9回） |
| 「合計時間 15分」 | 記録用 |
| 「9月号を全て完了しました」 | その月を完了（翌月のゲーム時間の判定に使う） |

**メールは翌日に届く**ので、「今日やったか」はメールでは当日中に分かりません。
今日の分は、進研ゼミの保護者サポートアプリ（日ごと）かタブレット本体で確認し、必要なら管理画面の「今日やったのを確認した」を押してください。
週や月の目標を達成していれば、その確認なしでも画面に「今日は休んでもOK」と出ます。

## 親がやること

**毎月の入力はありません。** 判定に必要なこと（やった日・レッスン数・月号の完了）はすべてメールから自動で取ります。
代わりに、知っておくべきときだけこのシステムからメールが届きます。

| いつ | 届くメール | 内容 |
|---|---|---|
| 毎月2日 8時 | 先月の結果と今月のゲーム時間 | 例:「兄 ✅ 完了 → 1日60分 / 弟 ❌ 未完了 → 1日0分」、昇格まであと何か月か |
| 毎月20日 18時 | のこり◯日です | **今月号が終わっていない子がいるときだけ**。全員終わっていれば届かない |

- 2日に送るのは、月末の最終日にやった分の完了メールが1日に届くためです
- 日付や送り先は `CONFIG` の `monthlyReport` / `reminderDay` / `notifyTo` で変えられます（`reminderDay: 0` で注意メールなし）
- 送らずに中身だけ確かめたいときは `previewNotifications` を実行すると実行ログに出ます

## 今月どれだけ進んだか

メールの「レッスン数」を月ごとに合計して、`10月 9日 / レッスン 18回（先月は全部で 52 レッスン）` のように表示します。
先月の合計が今月の目安になります（月によって必須レッスン数は変わるので、あくまで目安です）。

正確に `45 / 61` のような表示にしたい月だけ、管理画面の「進み具合を正確にする」から必須レッスン数を入れられます（**入れなくても判定には影響しません**）。
`CONFIG.progressPageUrl` に保護者サポートの学習状況のURLを入れておくと、管理画面の上にリンクが出ます。

> 保護者サポートのサイトに自動でログインして数字を読み取る仕組みは、あえて作っていません。
> ベネッセのID・パスワードをスクリプトに保存することになる、サイトの作りが変わると止まる、利用規約で自動アクセスが禁止されている可能性がある、の3つが理由です。

## セットアップ（15分くらい）

1. 通知メールが届く Google アカウントで https://script.google.com を開き、「新しいプロジェクト」を作る
2. `Code.gs` の中身をエディタに貼り付ける
3. 「＋」→「HTML」で `Index` という名前のファイルを作り、`Index.html` の中身を貼り付ける
4. 「プロジェクトの設定」でタイムゾーンを `(GMT+09:00) 東京` にする
5. `Code.gs` 冒頭の `CONFIG` を書き換える
   - `children` の `keywords` に、メールに出てくる名前（「ソラさん」なら `'ソラ'`）を入れる
   - `baseMinutes` にふだんのゲーム時間（兄 60、弟 30）
   - `progressPageUrl` に保護者サポート「学習状況」のURL（任意）
6. 関数に `debugLatestMails` を選んで「実行」し、Gmail へのアクセスを許可する
   → 実行ログに最新メールと読み取り結果（子ども・日付・レッスン数・完了した月）が出るので、正しいか確認する
7. `setup` を実行する（記録用スプレッドシート作成、1時間ごとの自動取り込み、お知らせメールの予約）
   → メール送信の許可も求められるので許可する
   → 実行ログに**管理画面のパスワード**（ランダムな10文字）が出るので控える
8. 「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」
   - 次のユーザーとして実行: **自分**
   - アクセスできるユーザー: **全員**（子どもの端末でGoogleログインが要らないようにするため）
9. 表示されたURLが管理画面。7 のパスワードでログインする
10. 子どもにも見せたい場合は、管理画面の各カードの下にある「子ども用リンク」を渡す

パスワードの変更は「プロジェクトの設定」→「スクリプト プロパティ」の `ADMIN_PASSWORD` で。

## ログインと見られる範囲

| 画面 | 開き方 | 見られるもの |
|---|---|---|
| 管理画面 | URL＋パスワード | 2人分すべて・操作もできる |
| 子ども用画面 | 子ども専用リンク（推測できないランダム文字列入り） | その子の分だけ（見るだけ） |

- ログインは6時間か、タブを閉じると切れます。パスワードを10回続けて間違えると15分ロック
- 子ども用リンクが家族の外に出たら、管理画面の「子ども用リンクを作り直す」で古いリンクを無効にできます

## 困ったとき

- **完了メールが来ていないのに実際は完了していた**（メールの取りこぼしなど）: 管理画面でその月を開いて「この月を完了扱いにする」
- **誰のメールか判別できない**と出る: `keywords` の名前がメールの表記と合っているか確認
- 月が変わってから完了した分は「期限切れ」として記録され、達成扱いにはなりません
