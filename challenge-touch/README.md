# チャレンジタッチ 月間レッスン管理

チャレンジタッチの通知メール（Gmail）を自動で取り込み、子ども2人の「今月のレッスン進捗」と「今日ゲームしてよいか」を表示する仕組みです。
Google Apps Script（無料）だけで動きます。サーバーの用意は要りません。

- **管理画面（親）**: パスワードでログインして、2人分の進捗・判定の確認、月のレッスン数の設定、完了数の修正をする。ログインしないと何も表示されない
- **子ども用画面**: 子どもごとの専用リンクで開く。自分の分だけを表示（見るだけで操作はできない）。ゲーム機のそばの端末でホーム画面に置く想定

## ゲーム判定のルール（`CONFIG.ruleMode`）

| モード | ゲームOKの条件 | 向いているケース |
|---|---|---|
| `pace`（初期値） | 月末に全レッスン終わるペースに乗っている | 毎日はできないが、月の全レッスンは必ずやらせたい |
| `daily` | 今日チャレンジタッチをやった | 今までどおりのルール（月の進捗は表示だけ） |
| `strict` | 今日やった、かつペースにも乗っている | いちばん厳しくしたい |

どのモードでも、その月のレッスンを全部終えたら月末までゲームOKです。

`pace` の目標数は「月のレッスン数 × 今日の日付 ÷ その月の日数」（切り上げ）で出します。
例えば30日の月に20レッスンなら、15日の時点で10レッスン終わっていればOKです。
先に進めておけば休む日を作れる一方、遅れたら追いつくまでゲームはできません。月末にまとめてやる状態を防ぐためのルールです。
`paceGraceLessons` を 1 にすると「1レッスン遅れまではOK」になります。

## セットアップ（15分くらい）

1. 通知メールが届く Google アカウントで https://script.google.com を開き、「新しいプロジェクト」を作る
2. `Code.gs` の中身をエディタに貼り付ける
3. 「＋」→「HTML」で `Index` という名前のファイルを作り、`Index.html` の中身を貼り付ける
4. 「プロジェクトの設定」でタイムゾーンを `(GMT+09:00) 東京` にする
5. `Code.gs` 冒頭の `CONFIG` を書き換える
   - `children`: 子どもの名前と、通知メールの中でその子を判別できる文字列（`keywords`）
   - `gmailQuery`: 通知メールを探す条件（差出人アドレスや件名で絞ると確実）
6. 関数に `debugLatestMails` を選んで「実行」し、Gmail へのアクセスを許可する
   → 実行ログに最新の通知メールと判定結果が出るので、子どもが正しく判別されているか確認する
7. `setup` を実行する（記録用のスプレッドシート作成と、30分ごとの自動取り込みを設定）
   → 実行ログに**管理画面のパスワード**（ランダムな10文字）が表示されるので控える
8. パスワードを変えたい場合は「プロジェクトの設定」→「スクリプト プロパティ」の `ADMIN_PASSWORD` を書き換える
9. 「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」
   - 次のユーザーとして実行: **自分**
   - アクセスできるユーザー: **全員**（子どもの端末でGoogleログインが要らないようにするため）
10. 表示されたURLが管理画面。開くとログイン画面が出るので、7 のパスワードでログインする
11. ログイン後、各子どものカードの下に**子ども用リンク**が出るので、それを子どもの端末で開いてホーム画面に追加する

## ログインと見られる範囲

| 画面 | 開き方 | 見られるもの |
|---|---|---|
| 管理画面 | URL＋パスワード | 2人分すべて・操作もできる |
| 子ども用画面 | 子ども専用リンク（推測できないランダム文字列入り） | その子の今月の進捗だけ |

- ログインは6時間で切れます。ブラウザのタブを閉じても切れます
- パスワードを10回続けて間違えると、15分ログインできなくなります
- 子ども用リンクが家族の外に出てしまったら、管理画面の「子ども用リンクを作り直す」で古いリンクを使えなくできます

## 毎月やること

- 月初めに、親用画面で各子どもの「今月のレッスン数」を入れる（チャレンジタッチ本体か、みまもるネットで確認）
- 完了数がずれていたら「この数に合わせる」で直す

## 完了レッスン数の取り込みについて（大事）

通知メールに書かれている内容が分からないため、**初期設定ではメールを「その日に学習した」という記録としてだけ使います**。完了レッスン数は親が入力します。

メールに完了レッスン数や完了したレッスン名が書かれているなら、`CONFIG.lessonPattern` に正規表現を入れると自動で数えるようになります。

- 「3レッスン完了」のように数が書かれている → `'(\\d+)\\s*レッスン'`
- 完了したレッスンが1行ずつ並んでいる → その行にだけある目印（例 `'✓'`）

手入力のままだと `pace` の判定は入力するまで更新されません。自動で数えられない場合、ゲーム前に子どもが本体の画面を見せ、親が数を入れる運用にしてください。
