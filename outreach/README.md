# 葬儀社向け 遺品整理メール営業ツール（半自動）

堺市近辺の葬儀社を集め → メアドを抽出 → 営業文面を自動生成 → **人が確認して**Gmailで送信、までを行う半自動パイプラインです。

> ⚠️ **最終送信だけは人が実行する設計**です（法務・到達率・炎上リスクのため）。「送信ボタンだけ人が押す」形になっています。

## セットアップ

```bash
cd outreach
npm install
cp .env.example .env   # → .env を自分の値で埋める
```

必要なもの:
- **Google Places API (New)** のAPIキー（Cloud Consoleで有効化）
- **Gmailのアプリパスワード**（2段階認証ON → https://myaccount.google.com/apppasswords ）
- **送信者情報**（会社名・住所・電話）※法律で表示必須

## 使い方（4ステップ）

```bash
npm run collect    # ① 堺市近辺の葬儀社 → data/leads.csv
npm run extract    # ② 各社サイトからメアド抽出 → data/leads-emails.csv
npm run generate   # ③ 文面生成 → data/outbox.csv + data/previews/*.txt
npm run send       # ④ ドライラン（送らず内容確認だけ）

# 内容を目視確認して問題なければ実送信：
npm run send:live  # 最終確認プロンプト(yes/no)あり。1日30通・30〜90秒間隔で送信
```

各ステップの成果物（CSV）は `data/` に出ます。手で編集してもOK（送りたくない行は消す等）。

## 調整したいとき

`config.js` を編集するだけ（コード本体は触らない）:
- 検索キーワード・エリア半径
- 営業文面（`{会社名}` などで差し込み）
- 1日の送信上限・送信間隔

## 法令・マナーの遵守（重要）

- **特定電子メール法**：広告メールは原則オプトイン。ただし「事業者がサイト等で公開しているアドレス」宛のB2B営業は例外的に可。本ツールは
  - 公開アドレスのみを対象（フォームのみの会社には送りません）
  - 送信者情報（名称・住所・連絡先）を全文に明記
  - 配信停止の方法を明記
  - `data/unsubscribe.csv` に載せたアドレスへは二度と送らない（`email` 列に追記）
- **送りすぎない**：1日の上限・送信間隔を守り、迷惑メール判定を避ける
- **相手サイトへの配慮**：巡回は待機を入れてあります

配信停止依頼が来たら、そのアドレスを `data/unsubscribe.csv` の `email` 列に追記してください（`generate`・`send` 両方で自動的に除外されます）。

## データの取り扱い

収集したリストや文面（`data/*.csv`）と `.env` は個人情報・秘密情報のため `.gitignore` 済みで、リポジトリにはコミットされません。
