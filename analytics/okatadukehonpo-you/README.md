# okatadukehonpo-you.com 計測設計 v2（既存構成への統合版）

既存コンテナ **GTM-P5Z8L54D** のエクスポートを土台に、必要な修正と追加だけを載せたものです。
既存のタグ・トリガーはすべて同名で含まれているため、**インポートしても削除は発生しません。**

| ファイル | 中身 |
|---|---|
| `GTM-merge-container-v2.json` | インポート用コンテナ（タグ10・トリガー5・変数2・組み込み変数15） |
| `src/cta-location-variable.js` | カスタムJS変数「JS - CTA設置場所」の中身 |
| `src/service-type-variable.js` | カスタムJS変数「JS - サービス種別」の中身 |

## 1. 何を変えたか

### 修正（実害があったもの）

| 対象 | 変更前 | 変更後 |
|---|---|---|
| トリガー `LINEクリック` | Click URL に **`line.me` を含む** | 正規表現 **`lin\.ee|line\.me|line\.naver\.jp`** に一致 |

LINE公式アカウントの友だち追加リンクは `https://lin.ee/xxxx` 形式が主流です。
`lin.ee` は `line.me` を含まないため、**この形式のリンクは GA4 のイベントも広告のコンバージョンも取れていませんでした。**
修正後はLINE経由のコンバージョンが増えます。広告レポート上で数字が跳ねますが、実装改善によるものです。

### 追加

| 種別 | 名前 | 内容 |
|---|---|---|
| 変数 | `JS - CTA設置場所` | クリックされたCTAがページのどこにあるかを判定 |
| 変数 | `JS - サービス種別` | URLパスからサービス種別を判定 |
| トリガー＋タグ | `メールクリック` | `mailto:` リンク → イベント `mail_click` |
| トリガー＋タグ | `動画再生` | YouTube再生開始 → イベント `video_start` |

### 更新

| 対象 | 変更内容 |
|---|---|
| タグ `電話タップ` | パラメータ `click_location` `service_type` を追加／配信を **ページにつき1度** に |
| タグ `LINEクリック` | 同上 |
| タグ `フォーム送信完了` | パラメータ `service_type` を追加 |
| タグ `広告CV 電話` | 配信を **ページにつき1度** に（誤タップ連打による重複コンバージョンの防止） |
| タグ `広告CV LINE` | 同上 |

### 変更していないもの

- `コンバージョンリンカー`、`GA4`（Googleタグ）、`広告CV フォーム` … **一切触っていません**
- トリガー `電話タップ`（tel: リンク）、`フォーム送信完了`（`.mw_wp_form_complete` の表示）… そのまま
- コンバージョンID `18308126022` と3つのコンバージョンラベル … そのまま
- **イベント名 `tel_click` / `line_click` / `form_complete`** … そのまま

イベント名について。当初は `tel_tap` などへの変更を想定していましたが、**変更しません。**
すでにGA4にデータが蓄積されており、名前を変えると過去データと分断されます。
分断のコストだけが発生してメリットがないため、既存の名前を維持するほうが合理的です。

## 2. インポート手順

1. **バックアップ**：管理 → コンテナのエクスポート（済みであれば不要）
2. 管理 → **コンテナのインポート** → `GTM-merge-container-v2.json`
3. ワークスペース：**新規**（`計測設計v2` など）
4. インポートオプション：**マージ → 競合するタグ、トリガー、変数を上書きする**
   - 今回は「上書き」を選んでも削除は発生しませんが、事故防止のため必ず**マージ**を選んでください
5. 確認画面で **「削除される数 0」** を確認する
   - 「更新される数」は5〜8件出ます。これは想定どおりです
6. 「ワークスペースに追加」（この時点では公開されません）

### カスタムディメンション（管理 → データの表示 → カスタム定義）

| ディメンション名 | 範囲 | イベントパラメータ |
|---|---|---|
| CTA設置場所 | イベント | `click_location` |
| サービス種別 | イベント | `service_type` |

登録して初めてレポートで分解できます。**登録前のデータは遡って分解できません。**

`click_location` に入る値：
`fixed_bar`（モバイル追従バー）／ `header` ／ `fv` ／ `price` ／ `case` ／ `contact` ／ `footer` ／ `body`

確実にしたい箇所は、HTML側でCTAの親要素に `data-cta="fixed_bar"` を付けてください。属性があればそれが最優先されます。

### その他

- データ保持期間を **14か月** に（初期値2か月）
- 自社IPを内部トラフィックとして除外

## 7. 通話コンバージョン（60秒以上）の追加

### なぜやるか

現在の `広告CV 電話` は **`tel:` リンクのタップ**を計測しています。タップは発信ではありません。
誤タップ・発信前キャンセル・即切りが混ざるため、自動入札が「タップされるが受注しない」キーワードに予算を寄せます。

Google広告の**転送番号方式**なら、実際の通話と**通話時間**を計測できます。
60秒以上だけをコンバージョンにすれば、誤タップと間違い電話がほぼ落ちます。日本でも利用可能です（転送番号は `0800` で始まります）。

### 前提条件

- サイトの電話番号が**テキスト**で表示されていること（画像は置き換えられないので不可）
- 電話番号の表記がサイト内で統一されていること
- 計測できるのは**広告クリック経由の訪問者のみ**。オーガニック・MEO・チラシ経由の電話は対象外

### STEP A：コンバージョンアクションの作成

1. ツールと設定 → 測定 → **コンバージョン** → 新しいコンバージョンアクション
2. **電話件数** を選択
3. **「ウェブサイトに掲載された電話番号への問い合わせ」** を選択
4. 設定内容
   - コンバージョン名：`通話60秒以上（サイト）`
   - 値：1件あたりの価値（粗利 × 成約率。不明なら後から変更可）
   - カウント方法：**1回**
   - **通話時間：60秒**
   - 「コンバージョン」に含める：**いったんオフ**（STEP Dで判断）
5. 保存すると **電話番号スニペット** が発行される

### STEP B：スニペットをサイトの `<head>` に設置

`src/call-conversion-snippet.html` が雛形です。発行されたIDと実際の電話番号に差し替えて使ってください。

**GTMでは代替になりません。** 既存のGoogle広告タグはクリック時にしか読み込まれないため、
ページ表示時の番号差し替えに間に合いません。

WordPressでの設置先（上から順に安全）

1. テーマの「head内にコードを追加」欄
2. WPCode / Head & Footer Code などのプラグイン
3. 子テーマの `functions.php` に `wp_head` フックで出力（`src/wp-head-snippet.php`）

**親テーマの `header.php` を直接編集しないこと。** テーマ更新で消えます。

電話番号は**サイト上の表記と一字一句同じ書式**で登録してください。
`072-377-6933` と `0723776933` は別物として扱われ、置き換わりません。

### STEP C：検証

1. 自分でGoogle広告を検索してクリックし、サイトに入る
2. 電話番号が **`0800` で始まる番号**に変わっていることを確認
3. その番号に発信し、**60秒以上**通話する
4. 数時間〜翌日、コンバージョンレポートに1件計上されることを確認

置き換わらない場合の原因：番号が画像／表記の不一致／広告クリック経由でない／転送番号の在庫切れ。
転送番号が割り当てられない場合は自社番号のまま表示されるだけなので、実害はありません。

### STEP D：入札の主軸を切り替える（すぐにやらない）

60秒フィルタでコンバージョン数は必ず減ります。自動入札は件数が少ないと学習できません。
**2〜4週間観測してから**、通話CVの月間件数で判断します。

| 月間の通話CV件数 | 対応 |
|---|---|
| 30件以上 | 通話CVを「コンバージョン」に、既存 `広告CV 電話`（タップ）を**セカンダリ**へ。主軸を入れ替える |
| 15〜30件 | フォームCV・LINE CVと合算して30件を超えるなら切り替え可。超えないなら据え置き |
| 15件未満 | **切り替えない。** タップCVのままにし、通話CVは観測用（セカンダリ）で保持 |

**タップCVと通話CVを両方「コンバージョン」にしないこと。**
同じ1本の電話が二重に計上され、自動入札が壊れます。必ずどちらか一方です。

### あわせて検討：電話番号アセットからの通話

広告に直接表示される電話番号（電話番号アセット）への発信も、同じく通話時間で計測できます。
サイトに来ずに発信する層を拾えるため、未設定なら追加を推奨します。
コンバージョンアクション → 電話件数 → **「広告からの電話」**。アカウント設定で**通話レポートを有効**にしておく必要があります。

### この方式で計測できないもの

取れるのは**広告経由の電話だけ**です。オーガニック検索、Googleビジネスプロフィール、チラシ、車両からの電話は対象外。
全流入の電話を測るにはコールトラッキングサービスの導入が別途必要ですが、まずは広告分だけで判断材料としては十分です。
