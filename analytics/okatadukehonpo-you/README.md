# okatadukehonpo-you.com 計測設計 v2（既存構成への統合版）

既存コンテナ **GTM-P5Z8L54D** のエクスポートを土台に、必要な修正と追加だけを載せたものです。
既存のタグ・トリガーはすべて同名で含まれているため、**インポートしても削除は発生しません。**

| ファイル | 中身 |
|---|---|
| `GTM-merge-container-v2.json` | インポート用コンテナ（タグ10・トリガー5・変数2・組み込み変数15） |
| `src/cta-location-variable.js` | カスタムJS変数「JS - CTA設置場所」の中身 |
| `src/service-type-variable.js` | カスタムJS変数「JS - サービス種別」の中身 |

## 1. 何を変えたか

### 修正（実害があったもの）

| 対象 | 変更前 | 変更後 |
|---|---|---|
| トリガー `LINEクリック` | Click URL に **`line.me` を含む** | 正規表現 **`lin\.ee|line\.me|line\.naver\.jp`** に一致 |

LINE公式アカウントの友だち追加リンクは `https://lin.ee/xxxx` 形式が主流です。
`lin.ee` は `line.me` を含まないため、**この形式のリンクは GA4 のイベントも広告のコンバージョンも取れていませんでした。**
修正後はLINE経由のコンバージョンが増えます。広告レポート上で数字が跳ねますが、実装改善によるものです。

### 追加

| 種別 | 名前 | 内容 |
|---|---|---|
| 変数 | `JS - CTA設置場所` | クリックされたCTAがページのどこにあるかを判定 |
| 変数 | `JS - サービス種別` | URLパスからサービス種別を判定 |
| トリガー＋タグ | `メールクリック` | `mailto:` リンク → イベント `mail_click` |
| トリガー＋タグ | `動画再生` | YouTube再生開始 → イベント `video_start` |

### 更新

| 対象 | 変更内容 |
|---|---|
| タグ `電話タップ` | パラメータ `click_location` `service_type` を追加／配信を **ページにつき1度** に |
| タグ `LINEクリック` | 同上 |
| タグ `フォーム送信完了` | パラメータ `service_type` を追加 |
| タグ `広告CV 電話` | 配信を **ページにつき1度** に（誤タップ連打による重複コンバージョンの防止） |
| タグ `広告CV LINE` | 同上 |

### 変更していないもの

- `コンバージョンリンカー`、`GA4`（Googleタグ）、`広告CV フォーム` … **一切触っていません**
- トリガー `電話タップ`（tel: リンク）、`フォーム送信完了`（`.mw_wp_form_complete` の表示）… そのまま
- コンバージョンID `18308126022` と3つのコンバージョンラベル … そのまま
- **イベント名 `tel_click` / `line_click` / `form_complete`** … そのまま

イベント名について。当初は `tel_tap` などへの変更を想定していましたが、**変更しません。**
すでにGA4にデータが蓄積されており、名前を変えると過去データと分断されます。
分断のコストだけが発生してメリットがないため、既存の名前を維持するほうが合理的です。

## 2. インポート手順

1. **バックアップ**：管理 → コンテナのエクスポート（済みであれば不要）
2. 管理 → **コンテナのインポート** → `GTM-merge-container-v2.json`
3. ワークスペース：**新規**（`計測設計v2` など）
4. インポートオプション：**マージ → 競合するタグ、トリガー、変数を上書きする**
   - 今回は「上書き」を選んでも削除は発生しませんが、事故防止のため必ず**マージ**を選んでください
5. 確認画面で **「削除される数 0」** を確認する
   - 「更新される数」は5〜8件出ます。これは想定どおりです
6. 「ワークスペースに追加」（この時点では公開されません）

## 3. GA4側の設定

### キーイベント（管理 → イベント → キーイベント）

| イベント名 | キーイベント |
|---|---|
| `tel_click` | ✅ |
| `line_click` | ✅ |
| `form_complete` | ✅ |
| `mail_click` | ✅ |
| `video_start` | ❌（中間指標のまま） |

キーイベントは1プロパティ30個まで。スクロール率や滞在時間は追加しないでください。

### カスタムディメンション（管理 → データの表示 → カスタム定義）

| ディメンション名 | 範囲 | イベントパラメータ |
|---|---|---|
| CTA設置場所 | イベント | `click_location` |
| サービス種別 | イベント | `service_type` |

登録して初めてレポートで分解できます。**登録前のデータは遡って分解できません。**

`click_location` に入る値：
`fixed_bar`（モバイル追従バー）／ `header` ／ `fv` ／ `price` ／ `case` ／ `contact` ／ `footer` ／ `body`

確実にしたい箇所は、HTML側でCTAの親要素に `data-cta="fixed_bar"` を付けてください。属性があればそれが最優先されます。

### その他

- データ保持期間を **14か月** に（初期値2か月）
- 自社IPを内部トラフィックとして除外

- [ ] フォームを実送信 → `form_complete` が1回だけ

- [ ] PCでも一通り確認

## 6. 今回やらなかったこと（と理由）

| 項目 | 理由 |
|---|---|
| イベント名の変更 | 既存データが分断されるだけで利得がない |
| フォーム入力エラーの計測 | MW WP Form のエラー要素のセレクタが未確認。当てずっぽうで入れると誤発火する |
| `広告CV フォーム` の配信オプション変更 | トリガーが既に「1度」なので不要 |
| GA4タグの測定ID参照方式の変更 | 現状 `measurementIdOverride` で正しく動いている。触る必要がない |
